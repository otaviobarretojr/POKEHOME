# POKEHOME

Nova base do Living Dex Hub F12.

Objetivo: manter a geração F12 isolada da base legada F11.8, com Pokédex universal, Box por jogo, coleção centralizada, formas/variantes e integração visual inspirada no DataDex.

## Estado

Bootstrap do repositório iniciado para receber o F12.25 Beta Candidate e a esteira Android via GitHub Actions.
